# 🗺️ Validador de CEP em Python

Este é um projeto em desenvolvimento de um script em **Python** focado na automação da validação e busca de endereços através do CEP. O objetivo principal do projeto é integrar a aplicação com uma API pública externa para agilizar a checagem de dados cadastrais, otimizando processos que costumam ser manuais.

## 🚀 Conceitos e Tecnologias Aplicados (Em Construção)

O projeto está sendo estruturado utilizando os seguintes conceitos fundamentais:

* **Biblioteca `requests`:** Utilizada para fazer a comunicação do código em Python com a internet.
* **Consumo de API Rest:** Integração inicial com a API pública do **ViaCEP** para enviar o CEP e retornar dados de localização.
* **Manipulação de JSON:** Tratamento inicial das informações recebidas (como rua, bairro e cidade) para exibição no terminal.
